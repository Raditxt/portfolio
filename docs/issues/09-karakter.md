# 09 · Karakter dan jadwal Aktivitas

## Tujuan
Pemanggilan, berjalan antar Spot, Duduk/Rebah, Berdiri/Bangun, Gelembung, lima Aktivitas.

## Di luar scope
Tanpa animasi selimut.

## Kriteria selesai
- [ ] Seam disepakati: `nextStep(state, fase, dt) → state`
- [ ] Tes untuk setiap pasangan Fase (misalnya Tengah malam → Pagi melewati Bangun lalu berjalan)
- [ ] Rebah tidak kaku: berbalik, duduk di tepi, rebahan
- [ ] Review visual kelima Aktivitas

## Catatan
Isi saat grilling: keputusan, asumsi, dan seam yang disepakati.
