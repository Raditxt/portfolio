# 01 · Scaffold project

## Tujuan
Next.js App Router + TypeScript strict, Vitest, Playwright, ESLint, deploy preview Vercel.

## Di luar scope
Tidak ada komponen 3D atau konten.

## Kriteria selesai
- [ ] `npm run dev` membuka halaman kosong
- [ ] `npm test` menjalankan satu tes contoh
- [ ] `npm run e2e` membuka halaman dan lulus
- [ ] `npm run lint` dan `npm run typecheck` lulus

## Catatan
Isi saat grilling: keputusan, asumsi, dan seam yang disepakati.
